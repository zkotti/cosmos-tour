# Bienvenido al Universo

El propósito de este repositorio es familiarizarse con los conceptos de Git y GitHub y practicar algunos comandos básicos. Además, el proyecto tiene como objetivo ofrecer un breve recorrido guiado por el cosmos por parte del [Department of Management Science and Technology][1] de la [Athens University of Economics and Business][2].

**En primer lugar:** Envía tu nombre de usuario de GitHub a [Zoe][3] (si aún no lo has compartido), y espera una invitación para unirte como colaborador del repositorio.

## Tareas
- Clona este repositorio.
- Agrega aspectos interesantes del cosmos al archivo **guide.md**. (Crea el archivo si no existe).
- Contribuye generosamente y en varias categorías.
- En caso de que reutilices material de otras personas, asegúrate de:
    1. reformular el contenido, y
    2. añadir una referencia a la fuente original.
- Introduce nuevas categorías y organiza el contenido.
- Siéntete libre de añadir imágenes y videos.
- Puedes modificar, corregir o mejorar el contenido existente añadido por otros.
- Confirma tus cambios.
- Envía (push) los cambios al repositorio de GitHub. (Si es necesario, obtén (pull) y resuelve cualquier conflicto de fusión (merge conflict)).
- Dado que eres un colaborador del repositorio, no se te pide que sigas la práctica de bifurcar (fork) y enviar solicitudes de extracción (pull request).

## Consejos
- Copiar y pegar texto se considera plagio, así que asegúrate de reformular cualquier contenido reutilizado.
- Configura tu editor para usar un corrector ortográfico (en caso de que aún no lo hayas hecho).
- Incluye enlaces donde sea necesario (*por ejemplo,* libros, videos en línea, *etc.*).
- Reorganiza el texto si crees que debería organizarse de manera diferente&mdash;¡siempre se aceptan refactorizaciones!
- Puedes incluir imágenes y videos, pero no olvides hacer commit y push de ellos.
- Las imágenes y videos deben colocarse en el directorio ```media/```. (Crea el directorio si no existe).
- Además, utiliza referencias para las imágenes y videos&mdash;no puedes reutilizar contenido web sin citar la fuente original.
- ¡Sé creativo! Lleva las cosas un paso más allá incluyendo un archivo con pautas de contribución para nuevos colaboradores, un código de conducta, una licencia, *etc.*

## Sistema de Calificación
- Número y calidad de las contribuciones&mdash;¡cuantas más y mayor calidad, mejor!
- Cada commit debe incluir una contribución o un grupo de contribuciones similares.
- ¡No combines varias contribuciones diversas en un solo commit!
- Completitud de cada contribución: las contribuciones de una sola frase se consideran "malas" contribuciones.
- Romper cosas (*por ejemplo,* conflictos de fusión) conlleva una deducción de calificación.
- ¡Pero reparar los errores de otros (*por ejemplo,* resolver conflictos de fusión) tiene un bonus!
- Calidad de los mensajes de commit: deben ser descriptivos (del cambio), concisos y seguir las mejores prácticas (*por ejemplo,* de [Robert Painsi][4] o [Bolaji Ayodeji][5]).
- Los mensajes de commit predeterminados no son bienvenidos.
- Las referencias faltantes o la reformulación de material reutilizado no son bienvenidas.
- El contenido debe estar en formato Markdown correcto&mdash;consulta el [Markdown Cheatsheet][6].
